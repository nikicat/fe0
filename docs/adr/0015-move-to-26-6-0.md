# 15. Move to Fe 26.6.0

- Date: 2026-11-11
- Status: accepted; its toolchain version is superseded by [0022](0022-move-to-26-7-0.md);
  supersedes [0009](0009-freeze-on-26-5-1.md) and the `Hasher` part of
  [0004](0004-literal-selectors-first.md)

## Context
Fe 26.6.0 makes `loop` a keyword, and it lowers `core::keccak` natively (argotorg/fe#1886).
Both change what Fe0 must do. [0022](0022-move-to-26-7-0.md) records the toolchain that Fe0
builds on.

## Decision
- Fe0 reserves `loop`, as Fe makes it a keyword ([0001](0001-strict-subset.md)).
- `core::keccak` lowers natively, so `sol("…")` selectors need no `Hasher` effect and no
  software keccak. This supersedes that part of [0004](0004-literal-selectors-first.md). The
  decision in 0004 to start with literal selectors still holds.

## Alternatives
- **Stay on 26.5.1:** a larger compiler, and seven known bugs, among them keccak that does not
  lower natively.

## Consequences
- A program that uses `loop` as a name is rejected by Fe0, as by Fe.
