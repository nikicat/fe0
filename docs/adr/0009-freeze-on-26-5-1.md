# 9. Freeze the toolchain on Fe 26.5.1

- Date: 2026-11-03
- Status: superseded by [0015](0015-move-to-26-6-0.md)

## Context
The submission must pin a Fe release. Fe changes fast: 26.5 alone changed reference semantics,
and master removes `std::io` character I/O. Fe 26.5.1 differs from 26.5.0 only by a parser-hang
fix, and `tools/spikes.sh` reproduces every recorded spike value on it.

## Decision
Build, test and submit on Fe 26.5.1, which CI downloads. Upgrade within the window only for a
blocking bug that only master fixes, and never rely on a feature that only master has.

## Alternatives
- **Track master:** gets fixes early, but any upgrade can break the build days before the
  deadline.
