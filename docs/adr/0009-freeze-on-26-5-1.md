# 9. Freeze the toolchain on Fe 26.5.1

- Date: 2026-11-03
- Status: accepted

## Context
The Fe team advised experimenting on master, but the submission must pin a release. Fe
changes fast (26.5 alone changed reference semantics), and master was about to remove
`std::io` character I/O. 26.5.1, released Oct 28, only fixes a parser hang over 26.5.0, and
`tools/spikes.sh` reproduces all 54 recorded spike values on it.

## Decision
Build, test and submit on Fe 26.5.1. CI downloads exactly that release. Master is watched by
hand (T0012), and we don't upgrade mid-window unless a blocking bug needs a fix that only
master has. A feature that exists only on master is never relied on.

## Alternatives
- **Track master:** gets fixes early (#1887, #1886 and native keccak landed in the window),
  but any upgrade can break the build days before the deadline.

## Consequences
- Known 26.5.1 bugs are worked around, and the workarounds are listed in WORKAROUNDS.md.
- An upgrade, if one happens, is explained in the README.
